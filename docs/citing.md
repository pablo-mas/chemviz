# Citing

chemviz is an independent reimplementation of published methods. If you use it in your work,
please cite the original articles of the methods you use:

- **TMAP**: D. Probst, J.-L. Reymond. *Visualization of very large high-dimensional data sets
  as minimum spanning trees.* J. Cheminform. 12, 12 (2020).
  [doi:10.1186/s13321-020-0416-x](https://doi.org/10.1186/s13321-020-0416-x)
- **MHFP and MinHash encoding**: D. Probst, J.-L. Reymond. *A probabilistic molecular
  fingerprint for big data settings.* J. Cheminform. 10, 66 (2018).
  [doi:10.1186/s13321-018-0321-8](https://doi.org/10.1186/s13321-018-0321-8)
- **UMAP**: L. McInnes, J. Healy, J. Melville. *UMAP: Uniform Manifold Approximation and
  Projection for Dimension Reduction.* arXiv:1802.03426 (2018).
  [doi:10.48550/arXiv.1802.03426](https://doi.org/10.48550/arXiv.1802.03426)
- **t-SNE**: L. van der Maaten, G. Hinton. *Visualizing Data using t-SNE.* J. Mach. Learn.
  Res. 9, 2579–2605 (2008).
- **openTSNE**, whose optimisation chemviz follows: P. G. Poličar, M. Stražar, B. Zupan.
  *openTSNE: A Modular Python Library for t-SNE Dimensionality Reduction and Embedding.*
  J. Stat. Softw. 109(3) (2024).
  [doi:10.18637/jss.v109.i03](https://doi.org/10.18637/jss.v109.i03)

The viewer draws structures with [RDKit.js](https://www.npmjs.com/package/@rdkit/rdkit), and
chemviz parses molecules with [RDKit](https://www.rdkit.org/).
